# NewsPaper Template — Adsterra integration

এই ZIP-এ আপনার পাঠানো নিউজ পোর্টালের HTML ফাইলগুলোতে Adsterra-এর ৫টি ফরম্যাট যুক্ত করা হয়েছে।

## যুক্ত করা হয়েছে
- Banner 300x250: প্রতিটি HTML পেজের মূল কনটেন্টের শুরুর দিকে এবং লাইভ নিউজের প্রতিটি কার্ডের আগে
- Native Banner: খবর/আর্টিকেল অংশের কাছে
- Smartlink: “বিজ্ঞাপন দেখুন” নামে স্পনসরড লিংক
- Popunder: বন্ধ রাখা হয়েছে, যাতে স্ক্রিনে ক্লিক করলে পপ-আপ বিজ্ঞাপন না খোলে
- Social Bar: প্রতিটি HTML পেজে body বন্ধ হওয়ার আগে

## Vercel-এ আপডেট করার ধাপ
1. ZIP Extract করুন।
2. `NewsPaper-Template-main` ফোল্ডারের ভেতরের ফাইলগুলো আপনার GitHub রিপোজিটরিতে আপলোড/রিপ্লেস করুন।
3. GitHub-এ commit করুন; Vercel সংযুক্ত থাকলে নতুন deployment হবে।
4. লাইভ সাইট খুলে মোবাইল এবং কম্পিউটারে পরীক্ষা করুন।

## গুরুত্বপূর্ণ
- বিজ্ঞাপন বাস্তবে দেখা যাবে কি না তা Adsterra অ্যাকাউন্ট/সাইট অনুমোদন, ট্রাফিক, ব্রাউজার সেটিংস এবং নেটওয়ার্কের ওপর নির্ভর করে।
- Social Bar ব্যবহারকারীর অভিজ্ঞতায় প্রভাব ফেলতে পারে; Adsterra-এর নীতিমালা অনুসরণ করুন।
- Smartlink-টি স্পষ্ট “বিজ্ঞাপন দেখুন” লিংক হিসেবে রাখা হয়েছে; ভুল ক্লিক করানোর মতো করে খবরের লেখা বা নেভিগেশন লিংকে লুকানো হয়নি।
- বিজ্ঞাপনের স্ক্রিপ্ট তৃতীয় পক্ষের ডোমেইন থেকে লোড হয়। নিজের Adsterra ড্যাশবোর্ড থেকে কোডগুলো আবার মিলিয়ে নিন।


## প্রতি সংবাদের আগে বিজ্ঞাপন
লাইভ নিউজ লোড হলে প্রতিটি সংবাদ কার্ডের শুরুর দিকে 300x250 ব্যানার ইউনিট এবং আলাদা রঙিন স্পন্সরড লিংক দেখানো হয়। বিজ্ঞাপনগুলো “বিজ্ঞাপন/স্পন্সরড” হিসেবে চিহ্নিত; সম্পাদকীয় সংবাদ লেখা বা মূল সংবাদমাধ্যমের লিংকের সঙ্গে মিশিয়ে দেওয়া হয়নি।
